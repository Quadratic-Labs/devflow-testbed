# Analyze & Review Skill

This skill provides comprehensive code analysis and review functionality.

## Usage

Invoke this skill to perform detailed analysis or reviews on code, files, or pull requests.

## Features

- Code quality analysis
- Review insights and suggestions
- Performance considerations
- Security analysis
- Best practices feedback

## Example

```
User: "Review this authentication module for security issues"
Skill executes bash commands and Claude analysis to provide comprehensive feedback
```

## Implementation

This skill combines:
- Bash command execution for file operations and metrics
- Claude's analysis capabilities for insights
- Structured feedback and recommendations
